# Results directory

Analysis scripts write generated outputs here; these are ignored by Git.
The exception is reference/, which contains the completed manuscript experiments
and is included in version control. Use downstream_retention (not legacy
source-inclusive retention) from these reference tables for the revised paper.

reference/sensitivity/ contains final distance-bin and fault-distance sensitivity
summary tables. These are archived outputs, not claims that the new release reran
all sensitivity ensembles. Original figure numbering is retained in filenames.
